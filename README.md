# 3b1b Artifacts

Illustrated lessons, one self-contained HTML page each.
Open a file in any browser, or browse them online at https://tcoratger.github.io/3b1b-artifacts/.

|---|---|
| [leanvm.html](leanvm.html) | leanVM from zero: the binary-field VM and its proof system (bus, GKR, sumcheck, WHIR, Keccak GKR, ring switching), leanXMSS, leanSPHINCS, LeanDA and recursive aggregation |

| [rlp.html](rlp.html) | Recursive Length Prefix (RLP): Ethereum's serialization of nested byte strings, decoding, and canonical form |
| [sphincs-leansphincs.html](sphincs-leansphincs.html) | SPHINCS+ and leanSphincs: hash-based signatures for Ethereum |
